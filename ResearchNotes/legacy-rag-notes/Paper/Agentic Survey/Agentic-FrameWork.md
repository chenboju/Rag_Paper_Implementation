
1.LangChain / LangGraph
LangChain：強調鏈式推理、多工具調用，支援多代理和自定義工作流。
LangGraph：LangChain 的分支，專為多代理與圖型工作流設計，易於實現 agent 間的動態互動。

2.LlamaIndex
模組化知識庫建構與文件索引，支援向量檢索、多資料源整合。
與 LLM 框架高度整合，易於串接多步查詢或知識強化工作流。

3.Hugging Face Transformers and Qdrant
Transformers：業界主流 LLM 與 Embedding 預訓練模型庫。
Qdrant：高效向量資料庫，常用於大型檢索增強（RAG）系統。

4.CrewAI
多代理任務協作框架，主打協作式 agent workflow。
支援自定義角色、分工與目標導向任務。

5.AutoGen
微軟開源多代理對話與協作平台。
可設定多角色 agent 協同完成複雜工作流，如自動編輯、審查、調用工具等。

6.OpenAI Swarm Framework
OpenAI 官方提出的多代理分群協作框架。
支援 agent 自主分工、反饋與調度，適合大規模自動化流程。

7.Agentic RAG with Vertex AI
Google Vertex AI 提供的 agentic RAG 解決方案。
結合 Google 雲端 AI 服務、向量檢索、企業級安全性。

8.Semantic Kernel
微軟推出的語意任務協作 SDK。
允許 LLM 與多種外部工具、程式腳本、知識庫互動。

9.Amazon Bedrock for Agentic RAG
AWS 端到端 LLM 平台，支援多模型部署與知識檢索。
提供企業級 agentic RAG 與 API 集成解決方案。

10.Neo4j
領先的圖資料庫平台，強化結構化資料查詢與圖型推理。
可與 LLM、RAG、Agent workflow 串接，用於知識圖譜、事件推理等應用。
